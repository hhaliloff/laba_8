# laba_5

## UDP Server (stub)

This repository contains a basic UDP server loop and shared request/response DTOs.
The `UdpServerMain` class is a minimal runner that starts the UDP server with a stub handler.

### Quick run (manual)

1. Compile with your existing classpath settings.
2. Run `UdpServerMain` and send a `Request` from the client.

Replace the stub handler in `server/src/UdpServerMain.java` with real command handling logic.
